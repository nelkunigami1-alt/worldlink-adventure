# WorldLink Adventure

This is the first Godot 4 3D milestone for the educational platform adventure.

## Run it

1. Install Godot 4.x from https://godotengine.org/download.
2. Clone or download this repository.
3. Open the project folder in Godot.
4. Press **F6** or **F5** to run the first Planet Share level.

The project is also editable in VS Code, but Godot is required to run the 3D game.

## Current controls

- **WASD / arrow keys:** move
- **Space:** jump
- Falling below the level respawns Linky.
